# 圈子最简界面（2026-10-26）

PC 入口位于 Learn 顶部图标栏，替换 Learn 原本禁用的错题本位置；Typing 错题本和底部微信社群保持不变。手机入口在主页“更多功能”。有效登录后启用；Pages 预览版禁用圈子。

## 使用流程

1. 创建圈子时填写名称和入圈口令；支持中文、英文或混合，例如“每天学 English”。展开“邀请同学”复制口令；朋友只输入口令即可加入。
2. 选择自己的圈子，查看今天及此前六天的打卡。
3. 手动提交今天的打卡，可选填写新学词数；给已打卡的同学点赞。
4. 成员可退出后重新加入；圈主可在“圈子管理”修改口令、移除成员或关闭圈子。修改口令后旧口令不能再加入，现有成员不受影响。

沿用后端每人最多三个圈子、每圈建议最多五十人的限制；不引入并发锁或硬人数保证。只展示七天数据，没有月度统计、排行或聊天。

## 数据与恢复

- 打卡由本人手动填写，仅在该圈分享，不自动提取、修改或同步学习记录。
- 成员暂以编号区分，服务端尚未提供成员昵称。
- 圈主在详情中直接看到“当前口令”并可复制。新版创建或重新保存的口令由私有服务端保存，仅向圈主返回，可跨设备查看。成员接口不会返回这项口令；成员自己输入的口令仍可保存在本机。旧版只有散列的圈子先使用原浏览器中的有效口令；若本机也没有，请在管理区重新设置。
- 口令为 2–32 个 Unicode 字符，去除首尾空白并按 NFC 规范化，英文区分大小写，内部空格保留。普通情况下不能使用其他圈子已占用的口令；并发重名时拒绝加入，圈主需更换口令。
- 创建前保存原始名称、口令和请求标识。网络结果不明时先刷新查看，可手动用原信息重试，不会自动创建第二个圈子。
- 请求只使用当前站点和当前登录身份。切换账户或退出登录后丢弃旧响应；不会为圈子清理登录凭据或学习数据。
- 普通打卡和点赞显示可能稍有延迟，页面提供手动刷新，不进行网络轮询。点赞和打卡只刷新圈子详情；历史日期只请求所选当天的数据。刷新时保留已有内容，完成权限检查后更新。
