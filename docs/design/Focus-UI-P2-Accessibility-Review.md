# Qwerty Plus · Focus P2：缩放与持续使用的稳健性

基于 `product/main @ 6cb7555`。P1 已提升错字反馈和 Block 完成页，本批只解决边界屏幕下的真实使用负担，不改变业务。

## 目标与当前发现

1. `Word` 逐字母呈现的父层原先 `w-fit` 且内部单行 `flex`，在**200% 浏览器缩放+长单词**时有横向溢出风险。修正方案：限制容器宽度、为右侧发音按钮保留 52px 空间，仅在不足容纳完整单词时折行，字母序号、字体配置和隐藏/提示逻辑保持。
2. `Layout` 固定 `h-screen`，低高度视口和高缩放可能压缩 Learn 统计、Footer 或学习区。修正方案：指定最小可用高度并允许浏览器自然滚动，不隐藏当前任务。
3. Learn `本轮加学` 出现时合法存在 **6 项**统计，而 P0 面板默认为 5 列；现在根据实际指标数量切换 5/6 列，900px 以下 3 列、520px 以下 2 列，避免第六项单独占行。
4. Block 结果页关闭图标原点击区域较小，调整为 44×44px 触控区并显式焦点样式，`disabled` 与同步 handoff 保留。

## 排除在本次功能改动之外

- 学习算法、每日固定词表、FSRS、Hint、ESC、输入字符、拼写发音、统计数值或同步均不变。
- 对 Review Gate 既有 P3 两条失败、双站 Explorer 版本差异与断言误差**不直接修改业务以强行过 Gate**。需要单独调查和证据收口。
- `master` / EdgeOne 不自动发布。

## 验收门槛

- 1024×430 + 200% 缩放、28 字母极长词：字母数量不变、任何字母不越出可见宽度、至少折为两行、可继续正常录入。
- 1280px 下模拟第六项统计：6 项一行；840px 下 3×2 网格；无遮挡、文本不消失。
- 860×560 下 Block 的关闭按钮点击区域不少于 44×44，阶段统计、继续按钮照常存在。
- 复用 P1 / P0 Focus 浏览器测试、导航弹窗回归、ESLint、生产构建和现有 Cloud V4/性能 Gate。截图按 SHA 归档。
- 各项通过后仅合入 `product/main`，Pages 构建结束后核对 `source-commit.txt`，供人工查看。

设计评判：功能界面在长单词、小屏与视力放大需求下仍保持“单词为主、清晰、安静、不会出现被裁切的信息”。
