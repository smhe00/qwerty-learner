# Qwerty Plus · Focus P1 实施与审查记录

> 2026-10-12，设计基线：`product/main @ 713fb2a`。承接 `Qwerty-Plus-Focus-UI-Architecture-v1.md`，在 P0 完成的安静视觉体系上细化使用中的情绪反馈。不替换应用结构。

## P1 的产品目标

- 保持单词为视线焦点；用户无需重新学习操作。
- 拼错时确认反馈，不用强烈摇晃或红色警报制造负面情绪。
- 成功时有微弱的结束信号，不给输入路径增加延迟。
- Block 成就感来源于真实完成量，不制造额外成就弹窗。
- 全流程不因字体、语义提示和提示升级而产生不必要的布局跳动。
- 低动作敏感用户可以完全消除非必需动画。

## 实际变更范围

### P1a — Focus Stage / Prompt / Feedback

| 项目 | 旧样式 | 新样式 | 不变语义 |
| --- | --- | --- | --- |
| 错误反馈 | 0.82 秒，水平 ±4px 抖动 | 0.26 秒，水平最多 1.5px 轻提示 | 错误记录、Hint/ESC 计数与推进规则 |
| 正确反馈 | 0.55 秒，放大 3.5% | 0.32 秒，放大 1.2% | 正确拼写提交与下一词时机 |
| 单词舞台 | 中央容器无独立高度约束 | 有界最小高度及稳定间距 | 单词字体尺寸与逐字符布局仍由原输入组件决定 |
| 释义/音标 | 多处硬编码灰色和透明度 | 引用 Focus 语义色、统一行高 | 显示/隐藏决策不变 |
| 例句 | 灰色一致呈现 | 中英文分层，英文稍强、中文略次 | 遮盖区域与完成后高亮逻辑不变 |
| Hint 辅助文案 | 暗色中较淡 | 更可读且更安静的文本色 | Hint 0～3/ESC 文字与键盘规则不变 |

### P1b — Milestone / Daily Completion

- 原有 `data-learn-block-pause`、`data-learn-daily-complete`、结算逻辑、自动同步状态、继续及关闭按钮原封不动。
- 当阶段达到里程碑或当日完成时，用细条强调色而非大面积奖励图形。
- 进度条采用 Focus 语义色，过渡由 500ms 缩至 240ms，带 `role=progressbar`、`aria-valuenow`。
- 五项统计依然五项、原字段、原公式；呈现为克制的紧凑网格；第一项今日/本轮进度高亮。
- 保留“按任意键继续”及同步期间按钮禁用；不主动播放发音、弹层或增加等待时间。

## 不得改变的边界

- `src/learn/`, `src/review/`, `src/sync/`、IndexedDB 业务、FSRS-6、V4/S1 及 32 词每日名单完全不涉及。
- 不修改 InputHandler、Letter 的字符映射、`Word` 的更新/判题函数，不伪造独立拼写证据。
- `Typing` 与 `Learn` 共用样式，但原来 Typing 的练习语义不变。
- 无新图标库、外链字体、网络图片、打卡奖励、排行榜或滚动阻塞动画。

## 验收矩阵

1. 深浅主题下，普通、拼错、正确、Hint、音标与例句可读，色阶清楚。
2. 1440×900、1280×800、1024×768 的 Learn/Typing 不出现异常裁切、Header 不挤占输入区。
3. ESC 全显示、冷测与独立拼写证据正确。
4. Learn 三词 Block 结束后显示里程碑、进度、五项统计，按任意键继续；同步未完成前不得离开。
5. 导航/统计弹窗关闭后保留输入状态，不触发底层 Escape。
6. `prefers-reduced-motion: reduce` 下振动和缩放动画被完全禁用。
7. Playwright、ESLint、生产构建均通过；历史 P3 状态探索失败单独记录、不归咎于本视觉变更。
8. 只合入 `product/main`；`gh-pages` 自动部署后核验源码 SHA；未经明确授权不更新 `master` 或 EdgeOne。

## 人工验收主观指标

- 第一眼焦点落在需要输入的单词，而不是数据和装饰。
- 错误没有“被惩罚”感；成功没有突然跳屏。
- Block 的庆祝自然、简洁；无需靠数字跳动、动画和彩纸制造价值感。
- 使用 10 分钟后仍显得安静、专业、舒适。
