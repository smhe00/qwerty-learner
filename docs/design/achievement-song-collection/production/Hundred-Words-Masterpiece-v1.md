## A. 定稿之前必须确认的视觉目标

- **一眼知道是博物馆级汝窑青瓷莲花碗**：碗沿薄而精确、腹弧和足有厚薄关系，天青釉深浅流转、微细开片、莲瓣写实刻纹、釉光温润而非卡通圆角桶。
- **像一张值得收藏的册页**：画面边缘为工艺真实的宣纸与宋锦、远景为清淡山水；题跋位置明确、留白有呼吸感。不是密集金边表格 UI。
- **朱砂确实是压出来的**：印模触纸前印位为空白；落下抬起留下带磨损/缺口的朱砂四字印，朱白文可读，无黑章；虚影为淡墨拓印。
- **原 Focus UI 未宋化**：只有成就弹出窗口内容置换，不新增全屏侧栏，不把用户的学习画面换成历史站首页。
- **锁定时有真实图片雾幕**：远山轻雾+近处流云分层，碗像藏品隐现而非一张 grayscale 卡，解锁后雾消散。
- **亮/暗双套素材**：亮是晴明宣纸与天青釉；暗是深黛馆藏纸、暖金灯影与未改变物理朱砂色的光感，非亮图反相。

## C. 图像生产提示词（美术，不是让图片生成 UI 字体）

**Scene / artifact 主提示词**（中英文混合仅作为生产指导）：

> 一幅中国宋代审美、艺术博物馆藏品质感的汝窑天青釉莲花纹瓷碗工笔静物。瓷碗有真实薄口沿、内敛足圈、温润半透釉层、极细开片纹、柔和金色口沿刻线；背景淡墨远山、稀疏松枝、宣纸纤维，边角为低对比宋锦曲水纹。高级雅致、克制留白、物理一致的器形体积感、层次丰富的绘画质地，不可幼稚卡通、不可游戏塑胶、不可现代霓虹。整幅画面必须预留足够空白承载后续 DOM 标题和印章。NO WORDS, NO LETTERS, NO TEXT, NO STAMPS, NO LOGOS, NO UI BUTTONS, NO USERNAME, NO DATES. Fine Chinese museum illustration, premium celadon glaze, rice-paper fibers, gilded details, restrained ink-wash landscapes, high-end craft realism.

对 **器物透明层** 单独描述碗体并要求 transparent background, no baked shadow outside alpha bleed。  
对 **暗主题场景** 要求“夜色馆藏、黛青与暗金，瓷面局部软光，保留宣纸物理纹理”，避免直接调低亮图曝光造成脏灰。  
对 **印章** 采取单独审字工序：图像模型常把汉字生成错，**字形必须人工审核或在独立合成层制作**；不能直接使用无法辨认的 AI 生成文字。

**负向审核清单**：合成器形错误、双碗重叠、把碗画成巨大玻璃容器、网格错位、廉价渐变、无意义饰边、伪文字、标志与水印、视觉焦点分散、高饱和渐变、印章成黑、古代器物的现代塑料高光。

## E. 动效时间线（样板锁定约 1.9 s）

| 时间 | 画面 | 交互安全 |
| --- | --- | --- |
| 0–250ms | Focus 背景逐渐云幕化，成就弹窗接管焦点 | 页面原有学习数据仍挂载 |
| 250–800ms | 完整画卷场景通过遮罩展开 | ESC 随时关闭 |
| 650–1050ms | 青瓷碗轻现，标题出现 | 无布局移动 |
| 1050–1370ms | 雕刻印模缓降至朱砂印位 | 尚未显示红印痕 |
| 1370–1520ms | 印模压纸，0.05–0.1 s 微震；朱色渗出 | 禁止再次发奖 |
| 1520–1650ms | 印模抬离，四字朱砂印留在册页上 | 状态只读 |
| 1650–1900ms | 获得日期/题跋出现，演出结束 | 恢复静态终态 |

重播按钮重新开始视觉状态，但不重复写 `achievementStates`、不会把历史收藏当成首次获奖。电脑用户若开启“减少动态效果”，默认静态，主动点击重播仍允许观看（先确认无障碍设计）。

## G. 人工审美与工程双 Gate

- **视觉审查**：把目标图与截图并排比较：器物体积、釉面、宣纸、宋锦、云纹、真实压印、标题留白、字体与整体秩序。尚未到“同一水平”直接 FAIL。
- **移动端/桌面**：320/390/768/1280/1440，亮暗两套；图片锐度、压缩噪点、布局、关闭与返回。
- **功能**：真实账号状态、错误/未解锁/隐藏、成就见过状态、入境动画及解锁动画区分，不影响每日新奖限额。
- **键盘/无障碍**：HeadlessUI Dialog 焦点，ESC 关闭成就后恢复 Learn ESC=不会，Reduced Motion、Tab、动态读屏提示。
- **稳定性**：背景/资源失效时文字功能仍可用；离线、慢网、多标签、刷新、取消动画，不会丢学习记录。
- **性能**：按需下载、视觉质量与体积权衡、杜绝打开成就前就预加载全部高清图。

**下一决策点**：只批准这一个精品样板的**图片母版**后，再扩展素笺墨印和泥金朱砂各一例；不要继续批量生产不合格 SVG 卡片。
