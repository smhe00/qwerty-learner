## A. 资源包层级与每张图片的用途

所有主题分成 **scene（完整画面） / artifact（器物透明图） / mist（近远雾） / seal（专属印章及印模） / transition（独立转场图）**。主题优先生成完整、无文字、无实印的静态画面，再从美术母版导出透明器物；需要完整合成图时也保留无文字的可组合版本。

| 素材 | 建议文件（以 `ACH_MASTERED_100` 为例） | 必须包含/排除 | 生产数量 |
| --- | --- | --- | --- |
| 亮场景母版 | `ACH_MASTERED_100/scene-light.webp` | 宣纸/边饰/山水；不得有标题、按钮、日期、已盖章 | 每个可见 P0 ×1 |
| 暗场景母版 | `ACH_MASTERED_100/scene-dark.webp` | 暗纸与暖金重新创作，而非 invert | 每个可见 P0 ×1 |
| 高质主器物 | `ACH_MASTERED_100/artifact.webp` | 透明汝窑莲花碗、釉裂纹、口沿微金、体积光 | 每个可见 P0 ×1 或共享经批准工艺族 |
| 近/远云雾 | `shared/mist/mist-near-light.webp` / `mist-far-light.webp` | 带 alpha，山气，不遮文字 | 通用各 2 主题 ×2 层 |
| 隐藏盲盒 | `shared/locked/secret-light.webp` / `secret-dark.webp` | 通用山影匣与浓云，不能暗示真实内容 | 亮暗 ×1 |
| 朱砂印章 | `ACH_MASTERED_100/seal-red.webp` | 专属朱白文，压印磨损真实、真红不黑 | 每个 P0 ×1 |
| 淡墨拓印 | `ACH_MASTERED_100/seal-ghost.webp` | 同章轮廓、低对比灰墨 | 每个 P0 ×1 |
| 动作印模 | `ACH_MASTERED_100/seal-press.webp` | 印模落下/压印，不是漂浮的红印痕 | 每个可演出奖项 ×1 |
| 弹窗卷轴母版 | `shared/scroll/scroll-light.webp` / `scroll-dark.webp` | 高分辨率木轴、帛面、宋锦/云纹、文字留白 | 亮暗 ×1 或按稀有度微变 |
| Focus 入境 | `shared/portal/portal-cloud-light.webp` / `portal-ink-dark.webp` | 独立半透明纸雾、墨云、暗金线 | 亮暗各 1–2 |
| 分享图（可选） | `ACH_MASTERED_100/share-scene.webp` | 无动态时间、用户名和按钮 | 发布分享功能后 |

**不合格资产**：把完整概念图截图当“网页背景”且带动态按钮文字；所有卡片用同一碗换标题；小于 320px 出现截断；直接给 `hidden` 锁定卡发送真实器物图；印章是纯色方框；汝窑碗仍靠浏览器 SVG 几何填充制造“瓷器”。

## C. 母版与切图尺寸

| 使用位置 | 美术设计母版（提案） | 发布变体 | 原则 |
| --- | --- | --- | --- |
| 成就总览卡片 | 1200×1600 | 1× / 2× WebP、现代手机可选 AVIF | 器物中心不得被裁；文本安全区贯通 |
| 藏品详情画卷 | 1600×2200 或由横卷构图确定的高宽比 | 1× / 2× WebP | 宽屏用画卷真实比例，不把横卷硬拉竖卷 |
| 专属器物 | 1200×1200 带 alpha | 按展示宽度生成 srcset | 保持器物绘画精度，阴影自然 |
| 印章 | 512×512（长方/葫芦据实际外形裁定）带 alpha | 1× / 2× | 手工审校字形与朱砂边缘 |
| 近远雾 | 1200×800（按背景安全区）带 alpha | 手机低分辨率 | 雾遮器物不遮 DOM 文字 |
| 转场纸雾 | 1400×900 带 alpha | 1×，按用户主题加载 | 每次进入静止后卸载动画 |
| 分享海报 | 1200×1600、1080×1920、1200×630 | 按导出任务生成 | 分享用图另走文字合成，不截图弹窗 |

**预算初值**：卡片单张目标约 ≤150KiB、详情首屏 1× 静态资源合计 ≤650KiB、共享两层雾约 ≤120KiB；任何因此明显降低美术精度的压缩都必须回退，先懒加载再压缩。静态图保留色彩空间 sRGB，检查压缩色偏/朱砂印章发黑。Git 仓库存放经过精修及许可校验的生产/参考素材，超大未定稿母版可在独立设计资产仓（须固定内容 hash）保存；上线不依赖外网图。

## D. 资产元数据 manifest（实施建议）

保存于 `src/achievement/visual-assets/manifest.ts`（静态打包映射）或 `public/assets/achievements/song/manifest.json`。必须具备：

- `achievementId`、`artVersion`、`tier`、`layout`、`light`、`dark`；
- 每个资源的路径、SHA-256、分辨率、长宽比、alpha 标识、文件大小；
- 每幅画的作者/生成方法、提示语版本、授权情况及审核人；
- 所有动态文字、印章与按钮的 normalized safe zone；
- 合规的锁定/隐藏映射：**隐藏项不得在未解锁的前端请求图文件**；
- `publishReady` 仅由美术+功能+浏览器审查通过后置为 true，禁止 CI 编译成功自动置位。

## E. 自动化与人工审美 Gates

1. 内容一致性：manifest ID 不重复且存在于实际 catalog，历史 award 不受影响。
2. 二进制校验：文件存在、格式符合、sha 命中、无意外动态文字、alpha 正确；图片 hash 变化要求重新视觉验收。
3. 性能：桌面冷缓存、手机 4G、懒加载、无错链、无超预算。
4. 视觉：目标参考图和实际实现的并排截图；纸感、器物、印、宋锦、文字留白；不能用纯 SVG 构图混过。
5. 行为：未解锁近远雾、隐藏信息保密、解锁后一键复原、亮暗主题过渡、Reduced Motion、ESC 与焦点、实时和历史状态严格区分。
6. 审核通过后才从研究分支向产品主线提交流程；任何未验收项目均保持“美术生产中”。
