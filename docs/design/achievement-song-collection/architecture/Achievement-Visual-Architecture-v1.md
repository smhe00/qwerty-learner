## 1. 核心决策

采用 **高完成度静态美术图像 + 动态文字/印章/日期 + 云雾状态层 + 前端合成动画**。器物、卷轴、宣纸、宋锦、山水、做旧、金泥等古朴美术必须优先由预生成的高质量图片承载，**不再以手绘 SVG 或少量 CSS 渐变代替视觉母版**。动态用户数据不得烘焙入底图。

**Focus UI 主体不变。** Learn、Typing、设置及其他弹窗沿用现有系统；成就仍通过工具栏进入 `/achievements` 的 `NavigationOverlay` 弹出子窗口。独立全屏预览页仅为艺术展厅，不是主站改版依据。所有云雾、入境和解锁仪式均限定于成就模块，默认不能拦截 Learn 的键盘输入、ESC=不会、暂停和会话恢复。

数据源仍为 `src/resources/achievementCulture/achievements.json` 与现有 `src/achievement/*`，列表只展示已启用且 `presentation.rollout === 'p0'` 的定义。视觉设计不改变发奖证据、FSRS、云备份 V4、账号工作区。发奖节奏沿用 `docs/ACHIEVEMENT_DIFFICULTY_PACING_V1.md`：自然日最多解锁一枚新永久成就；不允许为了动画模拟真实发奖。

## 2. 三档材质 × 四档业务稀有度

| 视觉材质 | 配色 | 业务稀有度 | 意境 |
| --- | --- | --- | --- |
| **素笺墨印** | 宣纸米白 `#F7F4ED`、松烟墨 `#2C2A29` | `common` | 浅纸、淡墨、稀疏纹路 |
| **汝窑天青** | 青瓷 `#7A9A95` | `rare` | 釉色、金线、温润体积感 |
| **泥金朱砂** | 金泥 `#C59B27`、朱砂 `#B83B2B` | `epic`、`legendary` | 稀有器物、华丽但克制的长卷 |

`hidden` 是保密维度，不是第四个稀有度。隐藏且未解锁时，不得向 DOM、图片预加载、ARIA 标签或 tooltip 泄露真名、稀有度、条件或专属器物图。

## 3. 分层合成（image first）

| Layer | 资源 | 责任 | 禁止 |
| --- | --- | --- | --- |
| A：场景母版 | 亮/暗各自完成的 WebP/PNG 底图 | 宣纸、宋锦边框、山水、云纹、卷轴肌理与气氛 | 烘焙动态文字、印章、按钮 |
| B：主器物 | 独立透明 WebP/PNG，按成就 ID | 汝窑莲花碗、折扇、书卷、玉佩、飞鸿等 | 用简单 SVG 几何代替主美术 |
| C：锁定云雾 | 远云/近云透明图片 + opacity/transform | 未解锁遮挡、若隐若现、解锁云开 | 遮住可读动态文本 |
| D：文字 | React DOM 文本与无障碍语义 | 标题、进度、条件、文化引文、日期、题跋 | 从图像 OCR 取文字、用画面示例日期 |
| E：印章 | 专属透明朱砂/淡墨图片、动作印模图片 | 未解锁拓影、解锁实印、压印后留痕 | 继承 `currentColor` 导致黑章 |
| F：动效 | CSS transform、clip-path/遮罩或 WAAPI | 入境、展卷、印模压下、云退、题跋显现 | 触发任何真实成就写入 |

“全图”表示场景**作为一幅完整艺术品**先设计并验收；为了动态叠字与落印，允许从同一个审定母版拆分场景/器物/雾/印章四层，并持有统一构图坐标。

动态安全区：`title`、`condition`、`culture`、`date`、`seal`、`controls` 六组规范化 0..1 矩形，分别给出可排版范围、字数边界及响应式锚点。单图支持 1x/2x 与不同裁切，不得因手机适配切掉主要器物或图案。实际时间采用 `AchievementStateRecord.unlockedAt`（Unix 秒），按客户端当前语言/时区格式化。

## 4. 未解锁云雾：隐约微露

**普通未解锁**：仍可按 `presentation.progress` 授权规则呈现标题和有限进度。器物主体采用降对比与透明雾层，柔雾横穿画面，只露 30–60% 关键轮廓。悬停/触摸时可小幅移雾增加趣味，但不得通过交互完全揭开、不产生朱砂实印。

**隐藏未解锁**：只用“秘藏”“静待机缘”等中性提示；画面为**匿名的云中匣/山影**，不预加载与真实成就绑定的器物资产。不能只是把真实卡片 `filter:blur` 后仍保留可查询的文字或 image src。

**已解锁**：近云消散，高清器物显露；同一成就使用专属朱砂印、真实解锁日期。再打开历史详情时显示静态收录状态，不重复播放“新获得”的庆贺仪式。

建议近雾与远雾分别用带 alpha 图片（亮/暗两套），动画仅用合成层 `translate3d/opacity`，浏览器低端设备或低动态偏好时保持静态云雾。雾的明暗是状态美术，不承担业务权限判断。

## 5. Focus UI → 雅集：有边界的场景转场

Focus 页面始终留在背景；`NavigationOverlay` 的 Headless UI Dialog、ESC/焦点管理、历史返回和原有键盘隔离保持不动。仅在成就内容容器内部播放纸幕与雾，不全局覆盖其他弹窗。

| 时间目标（可微调） | 明主题：晨雾入画 | 暗主题：墨夜启阁 |
| --- | --- | --- |
| 0–150 ms | 背景轻失焦，不闪白 | 学习背景轻压暗，不闪黑 |
| 150–350 ms | 浅云/宣纸从边缘包入 | 黛青墨雾渐聚、边缘微金光 |
| 350–650 ms | 淡山水与雅集藏品浮现 | 暗纸纹、温金卷轴轮廓显现 |
| 650–800 ms | 雾散，标题与操作区可交互 | 金光收束，正文和朱砂可读 |

亮主题用米白、薄青、淡金，气质温润；暗主题单独制作 **夜卷/暗纸/黛青山影/低亮暖金**，**禁止 CSS invert 亮图**。暗背景下朱砂仍必须呈红色（`#B83B2B` 是基准而非合成后的最终显示一定等于该色）。关闭弹窗 200–350 ms 内反向淡出，不阻塞学习操作。

系统 `prefers-reduced-motion: reduce` 默认不自动展开长动效；用户点击“重播钤印”才可主动触发。页面后台/刷新/路由中断/资源失败时直接切至完整静态状态；不会改变成就解锁、见过状态、云记录，也不 remount 学习会话。最小屏宽 320px，桌面按 1280、1440 验证。

## 6. 展卷钤印：从“红块飞来”修正为真正压印

真实解锁的视觉时序建议（仅展示，业务异步结果确认后才开始）：

1. **云起入境 0–250ms**：主题雾/纸幕过渡，背景 Focus 状态留存。
2. **画卷展开 250–800ms**：母版卷轴用遮罩 reveal；卷轴端轴可独立透明图片微移。
3. **见器题名 650–1050ms**：器物、主标题渐显，页面无重排。
4. **印模落下 1050–1650ms**：独立的印模动作图短程下降 → 触纸压印 → 微震 → 印模抬离或淡出，**红色印痕才留在纸面**，而非整张红印从天飞下。
5. **题跋终帧 1500–1900ms**：解锁日期、“落朱成印，录入雅藏”显现，彻底静止。

历史详情不冒充新解锁；点击重播只更改视觉时序，不触发成就评估/状态写入。音效默认关闭。所有按钮立即可退出，不应在 2 秒演出期间失去响应。首次入境短动效和真实获奖长仪式是**两个不同事件**。

## 7. 资源生产链路与结构契约

1. 从实际成就定义提取 `id / title / category / rarity / hidden / culture / artDirection`，校核现实门槛与历史作品典故；**生成图不包含任何需要动态更新的文字**。
2. 编写 visual spec：主题、器物、美术关键词、排版安全区、亮暗差异、专属印章样式、图片生产批次与生成/授权来源。
3. 使用静态图生成流程产出真实视觉母版，先单图人工审美：器物结构、史感、山水景深、釉面与纤维、宋锦纹、朱砂沉着感。达不到 [目标参考](../references/README.md) 质量则不进入组件。
4. 从同母版导出场景图、器物透明层、近远云、专属印章与印模动作层；按 ID 与语义命名，不随意重复使用同一张器物。
5. Manifest 固定文件名、内容 SHA、设计版本、比例、色彩空间、alpha、生成说明、版权确认以及该图可用于哪个状态；CI 做存在性与预算检查。
6. 前端只读 visual spec 与成就数据合成；预览用**模拟数据，不与 DB 交互**；正式实现联入已有持久化发奖队列。
7. 审图 + 浏览器回归后由用户确认，方可考虑合入开发主线。

示例展示适配结构（不写入 backup V4）：

```ts
type Rect01 = { x: number; y: number; w: number; h: number };
type VisualSet = { scene: string; artifact?: string; mistNear: string; mistFar: string };
type AchievementVisualSpec = {
  achievementId: string;
  artVersion: string;
  tier: 'ink' | 'celadon' | 'cinnabar';
  family: 'fan' | 'bowl' | 'jade' | 'scroll' | 'hidden';
  light: VisualSet;
  dark: VisualSet;
  seal: { ghost: string; cinnabar: string; press?: string };
  safe: Record<'title'|'condition'|'culture'|'date'|'seal'|'controls', Rect01>;
  provenance: { promptVersion?: string; creator: string; rights: string };
};
```

母版建议：卡片约 1200×1600（裁切按最终卡片构图设计），详情 1600×2200 或横轴卷轴同等像素密度；1x/2x 按需导出。透明图使用 PNG 或可保 alpha 的 WebP。卡片单张 1x 初始预算目标 ≤150KiB，详情首屏 1x 图片累计 ≤650KiB，云层两张累计 ≤120KiB；这是优化目标，不能以严重失真达标。详情只在打开时加载高分辨率资产，隐藏未解锁不得预拉取真实主图。存储优先放 `public/assets/achievements/song`，不使用运行时图片生成服务。

## 8. 原始需求原文（必须保留）

重塑宋代器物与书画设色：摒弃普通高饱和度卡片，以宣纸米白（#F7F4ED）为底、松烟墨（#2C2A29）为字，并按成就稀有度划分为“素笺墨印（初阶）”、“汝窑天青（中阶，#7A9A95）”、“泥金朱砂（高阶，#C59B27 + #B83B2B）”三档视觉层级。

定制篆刻朱白文印章（SVG）：为每项成就设计专属的宋式方印、长方印或葫芦印（含阴刻白文与阳刻朱文），未解锁时呈淡墨拓印虚影，解锁后盖上朱砂印章并显示解锁日期题跋。

绘制宋代雅器与宋锦纹样徽章：针对不同成就维度（如连击数、打字速度、坚持天数、词库通关）搭配极简工笔线条 SVG 器物图标（如折扇、汝窑青瓷莲花碗、玉佩、经折装书卷），卡片四周辅以极细的宋锦回纹或曲水纹内边框。

增加“展卷钤印”解锁动效：在成就达成弹窗中加入画卷展开与印章落下的微动效，让原本单调的文字提示变成类似“册页题跋钤印”的收藏体验。

**后续正式修订（原话）：**“古朴的部分尽量用图片，SVG可以不用（我不认为可以做成我们要的效果），做全图+文字动态叠加方案。” 原文 SVG 要求仅作为历史需求保留，当前实现主线以高质量图片资产为准。

## 9. Gate 和风险

- **Design Gate：** 首件藏品与原始目标图同屏比对，通过人工审美，不能拿自动化 lint/build 代替。
- **Asset Gate：** 校验素材确实存在、版权可使用、尺寸、alpha、安全区、亮暗版本、锁定隐私、名称唯一性。
- **UX Gate：** 焦点/ESC/键盘隔离、双主题、关闭中途、重播、最小屏幕、屏幕阅读器、加载降级、动画偏好。
- **Data Gate：** 真实日期/状态与成就分类不变；演示不写数据库；持久化成功后才有解锁仪式；断网和刷新不重复发奖。
- **Perf Gate：** lazy loading、图像传输预算、冷缓存首帧、手机内存、累计布局偏移、无常驻无限动画。
- **Release Gate：** 研究分支先经 CI 和视觉审查。未经明确批准不向 `product/main`、etest、master 推送。

**现状差距：** 独立预览已用 React/CSS/SVG 模仿汝窑碗、纸幕、朱砂印，但釉面、器物写实、历史构图和图像美术精度明显低于目标。此版本仅提供参考过渡与动画技术实验，**不代表“精品图资产方案已实现”**。
