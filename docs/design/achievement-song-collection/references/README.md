### 必须学习的视觉信息

1. **美术完成度**：前景真器物、淡墨山水、深浅有别的纸面、宋锦回纹、手工钤印、层层云雾；不是大面积 CSS 渐变。
2. **场景构图**：雅集目录为淡纸收藏墙，中心弹出卷轴具有纸张厚薄、竹木卷轴端、印泥质感；高完成度的典藏细节集中在“放大详情 / 解锁仪式”。
3. **器物语义**：折扇、飞鸿、天青莲花碗、经折书和葫芦分为不同的收藏主题；实际成就必须按现有 catalog 绑定，不照搬概念图里的示例名称和计数。
4. **颜色层次**：宣纸 `#F7F4ED`、松烟墨 `#2C2A29`、汝窑青 `#7A9A95`、金泥 `#C59B27`、朱砂 `#B83B2B`，并提供独立夜卷方案。
5. **从 Focus UI 进入雅集**：截图左侧的宋式整站侧栏只是“沉浸概念图的设计语言”，**不得据此重做 Focus UI 主壳**。在正式产品通过已有 `NavigationOverlay` 成就窗口局部引入宋韵世界。
6. **未解锁**：应在此风格基础上增加远近雾分层与秘藏遮罩；图片本身未展示完整状态机，所以实现按 [架构](../architecture/Achievement-Visual-Architecture-v1.md) 为准。

## 视觉比较要求

待真正图片母版制作完成后，以双主题和四种关键尺寸截图与本文件的目标视觉同屏对照。判定项：宋画氛围、青瓷釉纹、折扇真质、专属篆印质感、卷轴木轴体积、印模压印而非红块飞入、纸面安全区、隐藏不泄露、手机排版。**CI 绿并不等于通过本审美门槛。**
