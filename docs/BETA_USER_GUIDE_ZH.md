# QWERTY Plus Beta · 使用指南

> 适用版本：`0.2.0-beta.1`。以网站页脚显示的源代码版本为准。  
> 建议环境：桌面 Chrome / Edge。Beta 期间请定期保存本地完整备份。

## 开始学习

1. 进入网站后选择词库。学习中途可以退出，重进后会根据保存的进度继续。
2. **Typing** 用于打字、拼写熟悉和章节训练；**Learn** 用于分阶段新词学习与长期复习。
3. Learn 中**任意键开始**，**Enter 暂停**，**Esc 表示不会**并进入提示流程。提示帮助完成拼写，但不计为无提示的独立掌握。
4. 每日新词目标默认 **32 个**，可在设置中修改。系统会结合到期复习安排当天学习内容。

## 备份与恢复

学习记录首先存于**当前浏览器本机**，即使不注册云账号也能学习。数据设置提供：

- **导出完整备份**：建议定期保存到电脑。重要修改或跨账号恢复前务必先导出。
- **校验备份文件**：只读检查文件完整性，不会修改已有学习进度。
- **导入完整备份**：会用所选文件替换当前工作区，而不是合并。若备份来源账号与当前接收工作区不同，页面会给出警告并要求额外确认。
- **清除本地数据**：不可逆操作；只应在确认已保存备份后使用。

当前完整备份采用 gzip 压缩的 Backup V4 格式。页面日常操作省略格式版本，不影响文件安全校验。

## 可选的云账号与同步

注册登录后，学习数据和匿名工作区彼此隔离。登录时请确认当前工作区属于正确账号。

- **同步**会检查本地与云端版本。内容一致时无需上传；只有一方发生变化时，根据安全策略上传或下载。
- **每日学习会话完成**后系统可自动同步。可按需开启“每个 Block 完成后自动同步”，默认关闭。
- **数据冲突**发生在两边都更改了记录，或者刚从其他账号导入备份时。普通同步不能擅自决定保留哪一端。
- 遇到冲突，请先分别下载**本地完整备份和云端完整备份**，再进入“处理同步冲突”，明确选择**保留本地**或**保留云端**。前者可能覆盖云端版本，后者可能替换本机记录。
- 若同步返回失败、超时或提示提交状态不确定，先核对云端版本和 SHA，再决定下一步；不要连续点击覆盖或重复导入。

**云端不是端到端加密存储**。账号权限和 HTTPS 可以提供访问控制与传输保护，但具备云存储管理权限的一方理论上能够读取备份内容。不要将账号密码、备份或诊断文件发送给不可信的人。

## Beta 使用建议

- 对长期保存的重要进度，至少保留一份独立的完整本地备份。
- 不要同时在两台设备上无序覆盖同一账号学习数据；如出现不同步，以页面冲突检查结果为准。
- 主要验收环境为桌面 Chrome / Edge。手机端不保证拥有同等完整的 Learn 体验。
- 出现学习卡死、单词异常、声音或同步失败时，可以在**设置 → 开发诊断 → 导出现场诊断包**保存现场。该包可能包含个人学习记录，仅发给可信开发者。

## 已知边界

Beta 不承诺：多设备冲突自动逐词合并、客户端端到端云备份加密、所有设备上的一致移动端体验，以及针对每位用户已达到最优的记忆参数。功能与发布状态以当前代码、最新测试结果和正式部署版本为准。
