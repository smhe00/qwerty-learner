# QWERTY Plus Beta · 使用指南

> 2026-10-25 核对；产品 `0.2.0-beta.1`，已验收发布基线 `ea4ede53`。网站实际源代码版本与产品版本号应分别核对。

## 1. 开始学习

正式入口为 [q.smhe.cn](https://q.smhe.cn/)，手机可直接进入 [手机首页](https://q.smhe.cn/mobile)。不登录也能本地学习。

全新工作区默认：上海中考 2027、英音、每日 20 个新词、每阶段 10 词。阶段词数允许 1–50；已保存设置保持其原值。到期复习与新词一起构成学习安排，20 不是当天所有练习次数的上限。

桌面 **Typing** 用于打字和章节训练，**Learn** 用于新词与长期复习。桌面 Learn 任意键开始，Enter 暂停或继续，Esc 表示不会并进入提示流程。手机 Learn 使用触控界面，不需要依照桌面键盘流程操作。

提示帮助完成不等于独立掌握。完成页的练习进度、独立答对、需要巩固应分别理解；“多学五词/再学五词”是额外学习入口，不是另建云账号或清空当天进度。

## 2. 手机菜单

手机已提供词库、设置、成就、学习记录、账号与云同步等入口，以及手机学习入口。

- **学习记录**：按日期、词库查看记录与每日单词明细。练习次数、去重词数、复习数和记录到的输入时间不是同一个指标；浏览历史不切换当前学习词库或改写进度。
- **成就**：未解锁卡片保持不可展开；部分稀有成就保留隐藏信息。
- **账号与云同步**：管理账号、只读检查云端状态、同步、下载云备份、导出完整本地备份及校验文件。

手机功能已上线，但现有 Chromium 触控模拟验收不等于所有真机都已认证。锁屏恢复、软键盘、横竖屏、返回手势和 PWA 安装/更新仍须真机覆盖。

## 3. 匿名、账号与换设备

本机匿名空间和各账号本地空间相互隔离。已有账号登录不会自动吸收匿名记录；新注册时可按页面明确选择复制匿名数据。退出账号回到匿名空间，不能把“退出”当成清空账号记录。

云端仍采用**单一有效登录会话**。另一设备登录后，旧设备可能需要重新认证。旧设备保留的离线记录不能因此删除；在该设备上重新认证同一账号，再由同步流程协调。

同账号、结构受支持的分叉学习记录可以自动合并，不需要把正常分叉一律当作“保留本地还是云端”的手工选择。身份不一致、数据校验失败或不受支持的结构仍可能阻止自动处理。

## 4. 什么时候同步

本地保存不等于已经上传。登录/启动时进行完整 V4 检查；学习事件后台上传、空闲恢复和完整快照同步有不同职责。网络可用、认证有效且安全条件满足时，系统执行适用的自动流程。

每日全部完成仍可自动同步；“每个 Block 完成后自动同步”默认关闭，只影响本机当前账号。开启后阶段完成页显示状态，按页面允许的继续、重试或仅保留本地操作处理。

“刷新云端状态（只读）”只读元信息，**不是立即同步**，也不证明所有记录已收敛。不能把有网络、登录成功或看到一条上传成功提示理解为所有数据都已同步。

## 5. 备份与恢复

完整备份使用标准 gzip `qwerty-backup-v4`。桌面在数据设置操作，手机在“账号与云同步”页面操作。

**导出**保存当前工作区完整备份；**校验**只读检查文件；**导入**需要独立确认并替换当前接收工作区，不是追加或自动合并。跨账号文件需明确核对接收身份，匿名接收值为 `LOCAL-ANONYMOUS`。

导入前先导出并校验当前备份。导入不会直接授权覆盖云端；后续同步仍需重新检查。清除本地数据和删除账号是独立的重大操作，不能作为一般同步故障的处理方法。

## 6. 同步异常时

出现待同步、认证过期、HTTP 500、超时或提交结果不确定时，保留本机数据与现场。旧会话需重新认证时使用同一账号；不要改为另一个账号接收这份记录。

优先导出当前完整备份。只有自动安全处理仍无法完成，才进入高级恢复，先保存双方备份、核对身份，再决定是否执行明确的替换操作。普通用户无需自行计算 SHA。

排障可使用开发诊断入口保存现场；诊断包可能包含学习记录，只交给可信开发者。云备份没有客户端端到端加密，不要公开备份、密码或会话信息。

## 7. 当前边界

圈子不是已完成的用户侧功能；后台实验 API 不代表前端、退出/删除和隐私生命周期已经闭环。现有发布验收也不证明每位学习者已获得最优记忆效果。

后端曾出现间歇性注册失败和云版本观察异常，复验通过但仍有待定位事项，详见 [收尾清单](./release/BETA_CLOSEOUT_2026-10-25.md)。
