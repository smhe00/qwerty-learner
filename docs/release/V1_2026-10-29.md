# QWERTY Plus 1.0.0

This release covers desktop Typing/Learn, mobile memory practice, review, history, achievements, portable V4 backups and account-isolated synchronization with one valid login session. Offline learning is retained; supported divergent records reconcile through the existing sync pipeline after reauthentication.

Ordinary login/reload checks fresh authenticated remote metadata. When the cloud still matches the account's last full-sync baseline, local work remains local until the existing learning/block/background cadence or explicit sync. Logout does not add an automatic sync. Changed or unknown cloud state retains the guarded reconciliation path. This release does not promise startup under one second.

The interface fixes restore painted learning controls, isolate document CSS, repair clipped settings and provide visible recovery actions. Pages exposes local-only account presentation with zero authentication/sync requests; real networking is verified on etest.

- Automated browser evidence uses Chromium. Huawei/HarmonyOS and iOS/iPad Safari physical-device checks are not claimed.
- The repository retains 143 previously recorded TypeScript diagnostics; whole-repository zero-error type checking is not claimed. Relevant scoped checks and the production build remain required.
- Blob is eventually consistent; existing integrity, uncertain-write recovery and account isolation remain necessary. A source rollback does not restore user data.
- Circle latency work remains independently tracked; subsecond Circle performance and every future feature are not prerequisites or claims of this core-learning release.
- Public contact/community and dictionary-contribution channels remain unavailable and continue to say so.
