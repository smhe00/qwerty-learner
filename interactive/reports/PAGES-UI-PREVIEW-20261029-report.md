执行基线：`9ef113301f2a03b8f4528621e5eefda076672f24`。目标：product/main → GitHub Pages。状态：本地验证完成；推送后由 Pages CI 执行精确提交发布检查。此任务独立于 Circle 性能任务，未修改 CURRENT_TASK。

## 改动

- 恢复 Pages 桌面“登录 / 注册”入口；手机和平板保留原有入口。Pages 不展示遗留凭据为真实登录状态。
- 使用与 EdgeOne 相同的 `presentAccount` 组件、CSS、标签页、字段、密码显示、原生校验、注册密码确认和返回路径。Pages 专用呈现器没有认证/账号切换监听器；合法提交只显示本地预览结果并清空密码，不创建虚拟登录凭据，不写学习记录。
- 云禁用账号入口统一选择预览呈现器，避免已有隔离工作区意外装载真实账号操作。真实 EdgeOne 登录流程和网络 API 禁用边界保持原样。
- 在实际 Pages 构建中执行六种屏幕/主题的界面矩阵，使用真实 basename；同时保留原有 EdgeOne 矩阵。Pages 无云圈子/隔离账号恢复场景有明确适用范围说明，这些场景仍在 EdgeOne 补充矩阵检查。Pages 反馈提示及返回仍被检查。
- Pages 发布后的浏览器回归新增桌面/手机登录入口、本地提交、返回与零 API 请求检查。各套测试输出目录分离，防止后续套件清空前一套的审计证据。
- Pages 专项发现并修复云同步禁用提示的深色对比度问题：原配色仅 3.18:1，现使用统一主题前景色。
- AGENTS 记录 Pages 主验证策略，真实登录/同步/Blob 仍由 etest 验证。
