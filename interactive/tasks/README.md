# Agent Tasks

This directory contains executable task specifications written by
Chat/Architect/Reviewer for any compatible coding agent.

Naming convention:

```text
TASK-YYYYMMDD-NNN-short-name.md
```

Create new tasks from:

`interactive/templates/TASK_TEMPLATE.md`

After creating a task, update `interactive/CURRENT_TASK.md` to point to the
active task and its report.

Do not reuse an old task file for unrelated work. Create a new task ID instead.
